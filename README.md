# 我的 Trae 技能库

本仓库备份本机 `C:\Users\dizey\.trae-cn\skills\` 下的全部技能，每个技能一个独立文件夹。

## 目录结构

```
my-skills/
├── agile-pm-workflow/          敏捷产品经理需求产出工作流（7 步）
├── newshub/                    NewsHub 资讯检索技能
└── uipath-studio-automation/   UiPath Studio 自动化技能
```

## 恢复方式（换电脑 / 重装）

把需要的技能文件夹整体复制回 `C:\Users\dizey\.trae-cn\skills\` 即可，无需其他配置。

## 同步机制

- 本机新增技能 → 自动复制进本仓库对应文件夹 → 自动提交并推送到 GitHub
- 每天定时执行一次；安装技能后也会立即同步一次
