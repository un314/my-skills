## 恢复方式（换电脑 / 重装）

## 同步机制

- 本机新增技能 -> 自动复制进本仓库对应文件夹 -> 自动提交并推送到 GitHub
- GitHub 上新增的技能文件夹 -> 自动复制回本机技能目录
- 每天定时执行一次
